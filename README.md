# Subsistence effort negatively predicts skill among BaYaka foragers

Code, data, and analyses accompanying:

> Lew-Levy S., Ringen E.J., Benoit L., Ouamba Y.R., Boyette A.H., Pope-Caldwell S., Gettler L.T., Crittenden A.N. (2026). *Subsistence effort negatively predicts skill among BaYaka foragers.* (manuscript under review)

## Reproducing the analysis

### 1. Install the environment

The project uses [pixi](https://pixi.sh/) for environment management.

```bash
curl -fsSL https://pixi.sh/install.sh | bash    # if needed
git clone <repository-url>
cd foraging_returns
pixi install
.pixi/envs/default/bin/dot -c                   # register Graphviz plugins (one-time)
```

### 2. Run the pipeline

```bash
bash scripts/run_all.sh                # ≈ 1 hour wall-clock; --skip-fit skips refits if cached
```

`scripts/run_all.sh` chains the full pipeline:

1. Canonical model fit (`ln_nogp_meage_long`)
2. Mean-aggregation sensitivity fit (`ln_nogp_meage_avg`)
3. Extract headline numbers (`results/manuscript_numbers.json`)
4. Compute Shapley contributions for both fits
5. Compute mean-aggregation Shapley with the true value function (`results/ln_nogp_meage_avg/shapley_mean_agg.nc`)
6. Per-forager kcal summary (`results/kcal_summary.csv`)
7. Model comparison (PSIS-LOO across components, `results/model_comparison_*.csv`)
8. Main-paper figures 1–4 + the resource-by-skill EDA panel embedded in the supplement
9. Render the supplement to HTML and DOCX

### 3. Run individual steps

To fit just the canonical model:

```bash
pixi run python scripts/fit_model.py \
    --name ln_nogp_meage_long \
    --me-age --no-gp \
    --tune 2000 --draws 5000 --chains 6 --target-accept 0.95
```

After fitting, regenerate downstream artifacts independently:

```bash
pixi run python scripts/extract_results.py            # results/manuscript_numbers.json
pixi run python scripts/compute_shapley.py            # per-forager Shapley
pixi run python scripts/compute_shapley_mean_agg.py   # mean-agg Shapley (avg variant)
pixi run python scripts/compute_kcal_summary.py       # per-forager kcal averages
pixi run python scripts/make_figure2.py               # per-forager Shapley boxes
pixi run python scripts/make_figure3.py               # skill + effort by age
pixi run python scripts/make_figure4.py               # gender-stratified ψ
pixi run python scripts/eda_resource_by_skill.py      # supplement Fig. S25
pixi run quarto render docs/supplement.qmd            # supplement.html / .docx
```

## Data access

| Path | Contents | License |
|---|---|---|
| `raw_data/` | Real participant IDs, full resource attribution. **Not in the public repository.** Contact corresponding authors. | Restricted |
| `public_data/` | Anonymised IDs, no resource-level attribution, precomputed per-row kcal. | CC BY 4.0 |

`public_data/` is generated by `scripts/build_public_dataset.py`. It includes a precomputed `kcal` column on every returns/recall row, so the model can be refit end-to-end from the public dataset alone:

```bash
bash scripts/run_all.sh           # uses raw_data/ by default
# Or, from the public dataset:
pixi run python scripts/fit_model.py \
    --name ln_nogp_meage_long --me-age --no-gp \
    --tune 2000 --draws 5000 --chains 6 --target-accept 0.95 \
    --data-dir public_data
```

Per-resource figures (the resource-composition figures in supplement §3 and the resource-by-skill panel in supplement §8) require the resource-attribution columns of the full data and are not reproducible from `public_data/` alone; everything else is.


## Repository layout

```
foraging_returns/
├── foraging_model/          # PyMC model package
│   ├── model.py             # ForagingModel — joint effort + success + returns
│   ├── data.py              # ForagingData — xarray-backed dataset builder
│   ├── analytics.py         # Canonical (forager, date) dataset for figures
│   ├── priors.py            # Default Koster-derived priors
│   ├── counterfactuals.py   # Shapley contributions (and group counterfactuals)
│   ├── plotting.py          # Posterior visualisation utilities
│   └── cross_cultural_priors.json   # Snapshot of Koster posteriors used to derive priors
├── preprocessing.py         # Raw CSV → analysis-ready DataFrames
├── scripts/
│   ├── run_all.sh                  # End-to-end pipeline driver
│   ├── fit_model.py                # Fit a model variant
│   ├── extract_results.py          # Extract headline numbers → manuscript_numbers.json
│   ├── compute_shapley.py          # Per-forager Shapley attributions (best-top-k value function)
│   ├── compute_shapley_mean_agg.py # Per-forager Shapley with the true mean-aggregation value function
│   ├── compute_kcal_summary.py     # Per-forager kcal averages → kcal_summary.csv
│   ├── compare_models.py           # PSIS-LOO across observables × variants
│   ├── make_figure2.py             # Per-forager Shapley boxes
│   ├── make_figure3.py             # Skill + effort curves by age
│   ├── make_figure4.py             # Gender-stratified ψ
│   ├── eda_resource_by_skill.py    # Supplement Fig. S25 (parallel-coords by skill tercile)
│   ├── marginal_effects.py         # Skill/effort marginal-effect sweeps
│   ├── export_dashboard_data.py    # Web dashboard data exporter
│   ├── build_public_dataset.py     # Build anonymised public_data/ subset
│   └── _derive_priors.py           # One-off: derive Koster priors from cross_cultural_priors.json
├── docs/
│   ├── README.md                          # docs/ layout guide
│   ├── supplement.qmd                     # Supplementary materials (renders to HTML/DOCX)
│   ├── MODEL.md                           # Mathematical specification
│   ├── SHAPLEY_VALUES.md                  # Shapley methodology
│   └── internal/                          # Author-only scaffolding (gitignored)
├── dashboard/
│   └── foraging_explorer.html             # Static web dashboard (consumes export_dashboard_data.py output)
├── public_data/             # Anonymised public dataset (license: CC BY 4.0)
├── raw_data/                # NOT TRACKED — real IDs, full resource attribution (gitignored)
├── results/                 # NOT TRACKED — fitted models, derived data, figures (gitignored)
├── tests/                   # Pytest suite
├── pixi.toml                # Environment specification
├── CITATION.cff             # Citation metadata
└── LICENSE                  # MIT license for the code
```
